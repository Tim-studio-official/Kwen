# Kwen Script Hub

Простое desktop-приложение (Tkinter), которое:

- читает скрипты из **других веток GitHub** (через GitHub API),
- показывает их как "магазин" (store),
- позволяет добавлять выбранные скрипты в локальную "библиотеку" (library),
- при старте показывает заставку `img/kwenlogo.png` (когда вы добавите файл).

## Запуск

```bash
python3 app.py
```

## Как пользоваться

1. Введите `Owner`, `Repo`, `Branch`, `Scripts folder`.
2. Нажмите **Load from branch**.
3. Выберите скрипт в списке Store — увидите превью справа.
4. Нажмите **Add to library**, чтобы добавить в локальный список.

## Заставка

Положите ваш файл по пути:

```text
img/kwenlogo.png
```

При следующем запуске приложение покажет его в стартовом splash-окне.
